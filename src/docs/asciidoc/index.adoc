== 응답 상태 코드 및 메시지
.Status 코드별 의미
[cols="1,1,2", options="header"]
|===
|HTTP 상태 | Code | Description

|200
|OK
|일반적인 요청 성공 (응답 바디에 에러를 전송해서는 안됨)

|201
|Created
|성공적으로 리소스를 생성했을 때 사용

|202
|Accepted
|비동기 처리가 성공적으로 시작되었음을 알릴 때 사용

|204
|No Content
|성공하였으나 반환할 데이터 없음

|400
|Bad Request
|일반적인 요청 실패

|401
|Unauthorized
|클라이언트 인증에 문제가 있을 때 사용

|403
|Forbidden
|인증상태에 상관없이, 액세스를 금지할 때 사용

|404
|Not Found
|리소스가 없을 때 사용

|405
|Method Not Allowed
|HTTP 메서드가 지원되지 않을 때 사용

|406
|Not Acceptable
|요청된 리소스 미디어 타입을 제공하지 못 할 때 사용

|409
|Conflict
|리소스 상태에 위반되는 행위를 지원할 때 사용

|500
|Internal Server Error
|서버 내부 오류

|502
|Bad Gateway
|상위 서버 오류

|503
|Service Unavailable
|서버 다운/점검

|504
|Gateway Timeout
|응답 지연
|===
